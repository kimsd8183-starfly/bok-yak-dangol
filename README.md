# AI 건강 지킴이 — 복용약·진료 관리 PWA (MVP v0.1)

2026-11-21 · 02_기술 · 예산 0원 · 로컬 퍼스트 아키텍처

## 무엇을 만들었나
총괄 지시 7기능 중 **6기능을 MVP로 구현** (기능 6 "보험 적용 확인"은 API 제휴 없이는
법적·기술적으로 불가 → "청구 준비 서류 모음"으로 축소, 확장 단계 항목).

| # | 요구 기능 | MVP 구현 | 방식 |
|---|---|---|---|
| 1 | 처방전 관리(사진) | ✅ 서류 보관함 | IndexedDB (단말 저장) |
| 2 | 병력·알레르기 | ✅ 병력 탭 | localStorage |
| 3 | 복용 섭취 자동 알림 | ✅ 시간대(아침/점심/저녁/취침) | Notification API + SW |
| 4 | 병원 방문 일자 알림 | ✅ 일정 + 하루 전 알림 | localStorage + SW |
| 5 | 진단서·상급기관 서류 저장·취합 | ✅ 서류 보관함(종류 분류) | IndexedDB |
| 6 | 민간 보험 적용 확인 | ⚠️ 축소 — 청구 준비 서류 모음 | API 제휴 필요(확장 단계) |
| 7 | 병력 관리·치료 스케줄 | ✅ 병력 탭 + 일정 | localStorage |

## 핵심 설계 원칙 — 로컬 퍼스트
- **건강 데이터(사진 포함)는 절대 네트워크로 전송되지 않습니다.**
  - 텍스트: localStorage / 사진: IndexedDB — 전부 단말 안에만 존재.
  - 개인정보보호법 민감정보 처리 리스크를 구조적으로 최소화(처리자 책임 범위 축소).
- 백업: 사용자가 JSON 파일로 직접 내보내기/복원(클라우드 업로드 없음).
- 서버 비용 0원, 앱스토어 심사 불필요(PWA — 브라우저에서 홈화면 설치).

## 제한(정직 고지)
- iOS Safari는 PWA 푸시 알림 제약 — 알림은 앱을 열어둔 상태에서 우선 동작.
  정확한 시각 알림의 무인 동작은 네이티브 앱(스토어 배포, 비용 발생)이 필요.
- 복약 정보는 의학 조언이 아님 — 앱 내 고지 필요(법률 보고서 판정 연동).
- "치료 스케줄" 문구는 의료기기 규제 트리거가 될 수 있어 "진료 일정"으로 표기.

## 실행 방법
- 개발: `python -m http.server 8080` 후 브라우저에서 http://localhost:8080
- 배포: 정적 호스팅(GitHub Pages 등 무료)에 4개 파일 업로드 → HTTPS 필수
  (서비스 워커·알림은 HTTPS에서만 동작)
- 아이콘: icon.png 512×512 필요(현재 미생성 — 배포 전 준비)
